# Pre SDF: Hatching

This is a simpler effect which draws lines within the input shape bounds.

By default you'll get some diagonal lines.

Some of the parameters are the same as the previous effects - setting color, thickness, and output behavior with regards to the SDF.

<img src="/images/hatching-1.png" alt="img">

You can change the angle or use the dropdown to snap to straight vertical / horizontal. Spacing controls the density.

<img src="/images/hatching-2.png" alt="img">

You can also crosshatch with an independent angle control:

<img src="/images/hatching-3.png" alt="img">

Line widths can be randomized within a specified min / max range:

<img src="/images/hatching-4.png" alt="img">

The lines can be distorted using a "pattern" (Sine, Triangle, Square, or Random). These offer amplitude / frequency controls. By default, they will offset in direction perpendicular to the line (e.g. a horizontal line would get pushed up / down). But you can change the offset direction using the "angle offset" control.

<img src="/images/hatching-5.png" alt="img">

The "square" pattern can create a crude checkerboard, for example"

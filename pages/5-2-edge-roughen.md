# Pre SDF: Edge Roughen

This is a simple effect that adds noise to the boundary edges of an input shape.

The main controls are "Amount" (amplitude) and "Frequency".

At lower frequency it causes an ink-blot like effect:

![img](/images/roughen-1.png)

At higher frequency it gets more like static noise:

![img](/images/roughen-2.png)

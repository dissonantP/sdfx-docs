# Post SDF Tab - Border

This is the simplest effect in the Post SDF tab.

All it does is select a slice of the SDF (a certain brightness range) and color it.

I'll keep it brief. "Brightness" can be used to move the ring, and "Tolerance" changes its thickness.

<img src="/images/border-1.png" alt="img">

For example, here I've lovered the brightness (so the ring moves outward) and lowered the tolerance (so the ring becomes thinner):

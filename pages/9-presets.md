# Presets

The preset system lives in this control row:

<img src="/images/presets-1.png" alt="img">

It's pretty simple. You can click different options in the dropdown to change presets (note that changing presets will wipe your current configuration without warning).

To create a new preset based on current settings, click the "N" button.

To update the currently selected preset based on the current settings, click the "U" button.

And to delete the currently selected preset, click the "D" button.

Presets are stored on disk in photoshop's PluginStorage/ directory. This is platform dependent, for me on Mac it's in `/Users/<me>/Library/Application Support/Adobe/UXP/PluginsStorage/`.

There are some built in presets already which cannot be updated or deleted. These all assume you are working with a light-colored input shape over a dark background.
